# Contributing to Nexora AI

Thanks for contributing to Nexora AI.

This repository uses a branch-based workflow so that changes are reviewed and tested before reaching `main`.

## Workflow

1. Start from the latest `main` branch.
2. Create a new branch for your work.
3. Make focused changes.
4. Commit with a clear message.
5. Push your branch.
6. Open a Pull Request into `main`.
7. Wait for CI checks to pass.
8. Review the changes before merging.

## Branch Naming

Use descriptive branch names such as:

- `feature/<feature-name>`
- `fix/<bug-name>`
- `chore/<maintenance-task>`
- `docs/<documentation-change>`

## Commit Messages

Use short, meaningful commit messages.

fix: enforce verified email on review routes
